# Academic homepage maintenance

This repository is the source of truth for Chenglong Fu's GitHub Pages homepage at `https://infinitywings.github.io/`.

- Preserve the compact academic layout: conventional sans-serif text, high information density, a small portrait, modest certificate thumbnails, and short section spacing. Avoid large promotional headings, decorative feature cards, and oversized whitespace.
- Make scoped changes to `index.html`, `styles.css`, and `app.js`. This site needs no framework or build step.
- Keep publication titles, author information, acceptance/publication status, venue tracks, awards, dates, and research claims grounded in supplied or verified evidence. Do not infer attendance from a scheduled talk or publication from acceptance.
- Treat certificate PDFs as originals. Preserve their contents and the complete author lists in image previews.
- Preserve the Inter license when changing or packaging fonts.
- Never add private email exports, unpublished evidence inventories, credentials, local workspace paths, or unrelated files to this public repository.
- Check affected functionality and local asset links. For layout changes, inspect desktop and mobile rendering. For PDF changes, verify the complete rendered document.
- Pages publishes `main` from `/`. Inspect current repository state and preserve unrelated changes before committing. After an authorized publication, verify the Pages deployment and the live files.
- Keep repository visibility, Pages domain, and account settings unchanged unless the user requests an administration or hosting change.
